## Архитектурный рефакторинг

### Новая структура

```
handlers/
├── contest_handlers.py      # Обработчики конкурсов
├── guide_handlers.py        # Обработчики гайдов
├── message_handlers.py      # Обработчики сообщений админам
├── news_handlers.py         # Обработчики новостей
├── common_handlers.py       # Общие обработчики
├── admin_contest_handlers.py # Админские обработчики конкурсов
├── admin_user_handlers.py   # Админские обработчики пользователей
├── admin.py                 # Старый файл (можно удалить)
└── user.py                  # Старый файл (можно удалить)

services/
├── contest_service.py       # Сервис конкурсов
└── user_service.py          # Сервис пользователей

utils/
├── cache_system.py          # Система кэширования
├── user_cache.py            # Кэш пользователей
├── contest_cache.py         # Кэш конкурсов
├── cache_cleanup.py         # Очистка кэша
├── simple_locks.py          # Упрощенные блокировки
├── markdown_utils.py        # Утилиты Markdown
└── error_handler.py         # Обработка ошибок

config/
└── settings.py              # Централизованная конфигурация
```

### Преимущества новой архитектуры

1. **Разделение ответственности**
   - Каждый модуль отвечает за свою область
   - Упрощено тестирование и поддержка

2. **Сервисный слой**
   - Бизнес-логика вынесена в сервисы
   - Кэширование на уровне сервисов
   - Улучшена переиспользуемость

3. **Централизованная конфигурация**
   - Все настройки в одном месте
   - Типизированные конфигурации
   - Упрощено управление

4. **Обработка ошибок**
   - Централизованная система
   - Типизированные исключения
   - Улучшена отказоустойчивость
