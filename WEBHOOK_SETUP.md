# Настройка вебхуков для Telegram бота

## Что изменилось

1. **Добавлен Flask сервер** (`webhook_server.py`) для обработки вебхуков
2. **Обновлен bot_instance.py** с оптимизированными настройками
3. **Изменен main.py** для поддержки двух режимов работы
4. **Добавлен Flask** в requirements.txt

## Преимущества вебхуков

- ✅ **Высокая производительность** - нет постоянного polling
- ✅ **Масштабируемость** - может обрабатывать тысячи пользователей
- ✅ **Надежность** - меньше таймаутов и ошибок
- ✅ **Экономия ресурсов** - меньше нагрузка на сервер

## Настройка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте `env_example.txt` в `.env` и заполните:

```env
# Режим работы
BOT_MODE=webhook

# URL вашего сервера (должен быть HTTPS)
WEBHOOK_URL=https://yourdomain.com/webhook
WEBHOOK_HOST=0.0.0.0
WEBHOOK_PORT=8443
```

### 3. Запуск

#### Для разработки (polling):
```bash
BOT_MODE=polling python main.py
```

#### Для продакшена (webhook):
```bash
BOT_MODE=webhook python main.py
```

## Требования для вебхуков

1. **HTTPS сервер** - Telegram требует SSL сертификат
2. **Публичный IP** - сервер должен быть доступен из интернета
3. **Порт 443, 80, 88 или 8443** - стандартные порты

## Полезные эндпоинты

- `GET /health` - проверка здоровья сервера
- `GET /webhook_info` - информация о текущем вебхуке
- `POST /set_webhook` - установка вебхука
- `POST /remove_webhook` - удаление вебхука

## Тестирование

1. Запустите бота в режиме webhook
2. Проверьте `/health` эндпоинт
3. Отправьте сообщение боту
4. Проверьте логи на наличие ошибок

## Переход с polling на webhook

1. Остановите текущий бот
2. Установите `BOT_MODE=webhook` в .env
3. Настройте `WEBHOOK_URL`
4. Запустите бота
5. Проверьте работу

## Troubleshooting

### Ошибка "Bad Request: bad webhook"
- Проверьте, что URL доступен по HTTPS
- Убедитесь, что порт правильный
- Проверьте SSL сертификат

### Бот не отвечает
- Проверьте логи сервера
- Убедитесь, что вебхук установлен: `GET /webhook_info`
- Проверьте переменные окружения

### Таймауты
- Увеличьте `num_threads` в bot_instance.py
- Проверьте производительность сервера
- Оптимизируйте обработчики
