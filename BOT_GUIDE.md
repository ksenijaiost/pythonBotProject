## 🎯 Обзор бота

Telegram бот для сообщества Animal Crossing, предоставляющий следующие возможности:

### Основные функции
- **📚 Гайды** - доступ к руководствам по игре
- **🏆 Конкурсы** - участие в творческих конкурсах
- **📨 Сообщения админам** - обратная связь с администрацией
- **📰 Новости** - отправка материалов для газеты
- **👥 Управление пользователями** - админские функции

### Технические особенности
- **Высокая производительность** - оптимизированная архитектура
- **Кэширование** - быстрый отклик на запросы
- **Вебхуки** - масштабируемость для больших нагрузок
- **Модульность** - легко расширяемая структура

## ⚙️ Установка и настройка

### Требования
- Python 3.8+
- Telegram Bot Token
- SQLite база данных

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Настройка переменных окружения

Создайте файл `.env` на основе `env_example.txt`:

```env
# Токен бота
BOT_TOKEN=your_bot_token_here

# Режим работы (polling/webhook)
BOT_MODE=polling

# ID администраторов
ADMIN_ID_LIST=123456789,987654321

# ID чатов
CONTEST_CHAT_ID=-1001234567890
ADMIN_CHAT_ID=-1001234567891
NEWSPAPER_CHAT_ID=-1001234567892
CHAT_ID=-1001234567893

# Имена пользователей
ADMIN_USERNAME=admin_username
CHAT_USERNAME=chat_username
```

### Запуск

#### Режим разработки (polling)
```bash
BOT_MODE=polling python main.py
```

#### Режим продакшена (webhook)
```bash
BOT_MODE=webhook python main.py
```

## 🔧 Устранение неполадок

### Частые проблемы

#### 1. Ошибки MarkdownV2
**Проблема**: `Character '.' is reserved and must be escaped`
**Решение**: Использовать `safe_markdown_v2()` для текста

#### 2. Блокировки пользователей
**Проблема**: Пользователь не может отправить сообщение
**Решение**: Проверить статус блокировки в админке

#### 3. Ошибки базы данных
**Проблема**: Медленные запросы
**Решение**: Проверить индексы и оптимизировать запросы

#### 4. Проблемы с вебхуками
**Проблема**: Бот не получает обновления
**Решение**: Проверить SSL сертификат и доступность URL
